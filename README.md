# bili-math-modeling

用于分析 B站数学建模课程、复习课程方法和按所学方法解题的 Codex skill。

核心记录围绕每个方法的实际解题过程展开，包括有序步骤、每步可选方案、选择条件、对应公式、变量含义、计算检查和来源。

## 内置资料

- 大师兄《胎教级入门数学建模》的 35 个分集笔记。
- 23 份方法记录，覆盖综合评价、优化、图论、插值、拟合、微分方程、时间序列与聚类。
- 部分例题的重建计算、核对结果和课程说法的修正依据。

[方法步骤手册](references/BV1p14y1U7Nr/方法步骤手册.md) · [课程目录](references/BV1p14y1U7Nr/课程总览.md) · [Skill 入口](SKILL.md)

## 安装和使用

下载仓库，将包含 `SKILL.md`、`agents` 和 `references` 的整个目录放入 `~/.codex/skills/bili-math-modeling`。也可向 Codex 提供本仓库地址，请它使用 `skill-installer` 安装仓库根目录中的 skill。

在 Codex 中调用，例如

```text
用 $bili-math-modeling 按课上学过的方法做这道题，
每一步给出选择依据和对应公式，并验证计算结果。
```

```text
用 $bili-math-modeling 比较熵权法和 TOPSIS，
说明权重在每个步骤如何使用，并引用课程例题。
```

## 来源与覆盖

课程来源为[大师兄的知识库的 B站课程](https://www.bilibili.com/video/BV1p14y1U7Nr/)。笔记基于逐分集字幕和每个分集 12 个抽样时间点整理，包含补充推导与独立计算。第 5 个分集使用本地音频转写。各讲记录保留了未取得的原始代码、数据和画面公式等缺口。

仓库中的画面和字幕来源链接指向原视频及分集，计算核对材料随仓库提供。完整视频、整轨字幕和截图原文件由原课程来源提供。课程内容及其权利归原作者所有。

使用例题结果前请核对记录中的前提和验证状态。应用到新问题时，应重新检查数据、模型适用条件和求解结果。
