# P12 已核对画面代码（已结合整轨讲解）

来源[05:08画面](https://www.bilibili.com/video/BV1p14y1U7Nr/?p=12&t=308)，分辨率852×480。按画面重建的代码如下，不是下载取得的教师原文件，也未在MATLAB实际执行。

```matlab
f = [-40;-30];
A = [1 -1 0 240; 1 0 -1 120]';
b = [6;-1;-1;1200];
lb = [0;0];
ub = [+inf;+inf];
[x,val] = linprog(f,A,b,[],[],lb,ub);
```

画面显示`Optimal solution found`、x为4和2、val为-220。A先写成2×4再转置为4×2，各行分别为总人数、第一项最低人数、第二项最低人数、总资源；等式约束为空。

原问题是最大化，故原目标值应恢复为220。此前P11已用独立求解器和上界证明核对同一模型；本页保留课程显示代码与输出的画面证据，全讲分析另见正式笔记。
