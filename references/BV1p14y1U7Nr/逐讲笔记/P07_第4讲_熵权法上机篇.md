## 先确认本例走哪条路线

输入仍为P06的5个候选对象×5个指标。01:00—06:30先选择要正向化的列`[1,2,3]`，再逐列输入类型：年龄选1=成本型、身高选2=最佳点型、长相选3=最佳区间型。最佳身高输入180，长相区间输入`[80,90]`；学历成绩和收入保持原值。这些编号是程序菜单约定，不是数学指标值。

| M04步骤与选项 | 课程函数/操作 | 输入→输出及检查 |
| --- | --- | --- |
| S01-B1 成本型 | `Min2Max`，最大值减原列 | 年龄→1、2、2、1、0 |
| S01-C 最佳点 | `Mid2Max(X,best)`，先最大绝对偏差再变换 | 身高、180→1、.5、0、.5、0；M不得为0 |
| S01-D 最佳区间 | `Int2Max(X,a,b)`，按区间三分支 | 长相、80、90→0、1、.75、1、.95；边界与M须有效 |
| S02-A 非负数据 | 元素平方→列求和→开根→逐元素除法 | 各列长度标准化，保留5×5形状 |
| S03 列比重 | `P=stand_X./repmat(sum(stand_X),n,1)` | 各列和为1，代码明确消除P06分母歧义 |
| S04 课程近似分支 | 将0替换为.00001，然后`sum(-P.*log(P))` | 先得到未归一H；零替换有近似误差 |
| S04/S05 后续 | `e=H/log(n)`；`d=1-e`；`w=d./sum(d)` | 输出5个权重，不是5个候选对象得分 |

标准化代码中的`repmat(sum_X,n,1)`是把1×m列统计量重复n行，得到n×m矩阵。字幕把它说成“n行一列”容易误解：n、1是复制次数，结果并非n×1。这里原矩阵恰好5×5，换成n≠m的题更应检查维度。

## 实现中需要保留的两个问题

**负值分支缺分子括号。** [08:35代码](https://www.bilibili.com/video/BV1p14y1U7Nr/?p=7&t=515)扫描整个矩阵，一旦发现负值就对全体列走else分支。意图是最小—最大归一，但画面写成

```matlab
stand_X = X - repmat(min_X,n,1) ./ ...
    (repmat(max_X,n,1)-repmat(min_X,n,1));
```

`./`先于减法，应将分子写为`(X-repmat(min_X,n,1))`才表示所需公式。[MathWorks运算次序](https://www.mathworks.com/help/matlab/matlab_prog/operator-precedence.html)。补充反例列[-1,1]：画面表达式得到[-.5,1.5]，正确变换应得[0,1]。课堂当前数据非负，所以该错误分支没有影响本例显示结果；这不能证明其适用于带负值的新数据。零极差、零范数也未见完整保护，不能照搬后宣称通用。

**零替换不是精确处理0ln0。** [14:13代码](https://www.bilibili.com/video/BV1p14y1U7Nr/?p=7&t=853)写`.00001`，字幕识别为`.0001`，以可读画面为准。直接替换0而不再归一，使前三列比重和变为1.00001、1.00002、1.00001。它能绕过`log(0)`，却改变原分布；推荐的补充实现是只在p>0处计算$p\ln p$，零项按极限取0。若选择显式平滑，则应说明方案并重新归一，不能与精确极限混称。

## 自测

1. 为什么向量类型菜单要与列编号分开？——前者选转换公式，后者选处理哪一列。
2. `repmat(sum(Z),n,1)`是什么形状？——n×m；它复制1×m行向量n次。
3. 看到本例输出正确，能否认定负值分支也正确？——不能，当前输入没触发该分支。
4. 替换0以后还可宣称P每列严格和为1吗？——不能，除非重新归一；应保存实现差异。
5. 本讲权重能直接比较五个候选人的名次吗？——不能，权重对应指标，还需明确评价模型。
