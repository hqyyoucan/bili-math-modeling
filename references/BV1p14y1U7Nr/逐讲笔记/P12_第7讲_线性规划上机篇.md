# P12 第7讲：线性规划上机篇

已逐段阅读109段B站字幕（1234字，0.74—340.76秒），查看12个抽样时间点，并细读10、11号852×480原视频图。方法继续使用[M07](../方法步骤/M07_线性规划.md)，本讲主要落实人员分配例子的参数录入。

## 按标准型逐项输入

画面确认的重建代码如下，详见[原始画面及转录](../原始材料/P12/画面代码转录.md)：

```matlab
f = [-40;-30];
A = [1 -1 0 240; 1 0 -1 120]';
b = [6;-1;-1;1200];
lb = [0;0];
ub = [+inf;+inf];
[x,val] = linprog(f,A,b,[],[],lb,ub);
```

| M07步骤 | 本讲具体操作 | 形状与公式含义 |
| --- | --- | --- |
| S02-B 最大化转最小化 | f中录入-40、-30 | 2×1目标系数；恢复原目标时再取负 |
| S04 整理不等式 | 先录入两条变量的系数，再转置 | 2×4原输入转成4×2的A，不能漏末尾转置 |
| S03/S04 右端常数 | b为6、-1、-1、1200 | 4×1，与总人数、两项下界、总资源四行一一对应 |
| S03-C 无等式 | Aeq、beq均`[]` | 没有额外线性等式，不能写成0或漏掉参数位置 |
| S03-D 变量界 | lb为0、ub为正Inf | 额外x≥1已由A的负单位行表达，没有因lb=0丢失 |
| S05/S06 求解与恢复 | linprog返回x、val | x=(4,2)，val=-220，原最大目标220 |

分号分隔向量的不同行，不能把f、b、lb、ub误录成不同长度。A中的转置只是录入习惯，直接按4条约束逐行构造4×2矩阵也等价；本例系数全是实数。

## 自测

1. 为什么A录入后要转置？——初始为2×4，而4条约束、2个变量需要4×2。
2. lb是0为什么仍保证每项至少1人？——A的第二、三行已含-x1≤-1、-x2≤-1。
3. val=-220是否意味着原收益为负？——否，求解的是负目标，原最大值为220。
4. 投资练习能直接输出唯一分配吗？——不能，尚需固定M、a及模型约定。
