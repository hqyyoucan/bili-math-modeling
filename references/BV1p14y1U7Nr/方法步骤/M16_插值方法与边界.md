# M16 插值：步骤、构造公式与边界选择

来源：[P24](https://www.bilibili.com/video/BV1p14y1U7Nr/?p=24)，00:00—30:40，含上机。输入采样点(xi,yi)、可选导数和查询位置；输出通过规定数据/导数的函数及查询值，不保证恢复唯一真实规律。路线：检查节点→区分维数与目标→选构造→确定边界/外推→计算验证。

## S01 检查数据与唯一性条件

一维输入xi须互异，按xi排序时yi同步；n+1个节点的次数≤n插值多项式唯一，不是所有过点函数唯一。范德蒙矩阵Vij=xi^j（i,j=0..n），det V=Πi<j(xj−xi)≠0，所以rank=n+1。02:49课件写rank=n是笔误。若重复xi对应不同yi，不存在单值精确插值；测量噪声不自动因插值而消失，拟合/平滑是另外的目标。

查询q∈[min xi,max xi]是区间内插值，超出为外推；定义域限制如log只允许正数另检查。采样数据不足以证明点间形状、导数或奇点行为。

## S02 按输入/要求选择方法

| 选项 | 条件 | 对应下一步与输出 |
| --- | --- | --- |
| A 分段线性 | 局部连接、只需连续、避免高阶全局构造 | S03-A，每段一次，多段整体通常非单一多项式 |
| B 拉格朗日 | 希望直接表示次数≤n的全局过点多项式 | S03-B，基函数求和 |
| C 牛顿均差 | 同一全局多项式，以逐点构造/便于增加节点表示 | S03-C，均差表和嵌套求值 |
| D Hermite | 除函数值外确有给定导数约束 | S03-D；不能凭未知真实导数捏造输入 |
| E PCHIP | 只有函数值，希望分段三次并尽量保形 | S03-E；节点斜率由算法估计，不等于已知真实导数 |
| F 三次样条 | 希望区间拼接后二阶导连续 | S03-F及S04边界条件，不自动保单调/无过冲 |
| G 二维规则网格 | V对应二维网格；查询曲面z=f(x,y) | S05，interp2及方法参数；散乱点不能直接假装规则网格 |

A/B/C是不同构造，课程把拉格朗日/牛顿称为“分段线性”不正确。对相同互异节点和次数限制，B/C给相同多项式；换写法不能从根本消除同一全局多项式的振荡。

## S03 构造：各选项的公式与检查

### A 分段线性

对x∈[xi,xi+1]，hi=xi+1−xi>0，S(x)=(xi+1−x)yi/hi+(x−xi)yi+1/hi。输入相邻两节点，输出该段值；在节点吻合，全局C⁰，一阶斜率可在拼接处跳变。C⁰不等于任何位置都不可导，直线段内部可导，斜率偶然相同的节点也可导。

### B 拉格朗日全局多项式

Li(x)=Πj≠i (x−xj)/(xi−xj)，Pn(x)=Σi=0..n yi Li(x)；Li(xj)=δij。输入全部节点，输出次数至多n多项式。分母需互异节点；n=1时恰为单条直线，不据这一特例把所有拉格朗日称分段线性。高次数/不合适节点可能振荡，次数越高不保证越准确。

### C 牛顿均差全局多项式

f[xi]=yi；f[xi,…,x(i+k)]=(f[x(i+1),…,x(i+k)]−f[xi,…,x(i+k−1)])/(x(i+k)−xi)。逐阶生成表，bk=f[x0,…,xk]，Pn(x)=b0+Σk=1..n bk Πj=0..k−1(x−xj)。最后一项只有n个线性因子，不能再乘(x−xn)。11:23课件末两项积的下标比系数阶数多一个，按该公式纠正；前面低阶示范与均差定义另行保留。

检查每阶分母非0、bk量纲与乘积匹配、代回全部节点。课程表的“均差”即差商，不必等距。递归增加节点不意味着旧多项式已被拟合为不同理论对象。

### D Hermite给定导数

课程12分钟附近要求H(xi)=yi、H'(xi)=di；抽样帧未取得其完整闭式构造，不能把另写公式当课堂原式。为便于执行，补充两端三次Hermite构造：t=(x−xi)/hi，

H_i(x)=(2t³−3t²+1)yi+(t³−2t²+t)hi di+(−2t³+3t²)yi+1+(t³−t²)hi d(i+1)。

输入两端值及斜率，输出过值/过导数三次段。di须有来源或标为估计；局部/全局Hermite、给不同阶导数约束是不同方案，本课未完整推导所有变体。过节点和导数也不保证整个区间真实形态完全一致，误差余项还需要相应光滑性假设。

### E PCHIP分段三次保形

使用上面Hermite段公式，但di由PCHIP从采样斜率估计；实际操作p=pchip(x,y,q)。需有序互异节点、数据形状匹配，结果在节点吻合且一阶导连续，二阶导通常可跳；不把它当全局C²样条，也不声称真实导数已测得。课堂未推导斜率选取/端点限制的全部规则，保留为算法内部而非编造课堂公式。节点数增加不增加每段三次的阶数。[官方pchip](https://www.mathworks.com/help/matlab/ref/pchip.html)。

### F 三次样条：先列方程，再选边界

n+1节点有n段，每段Si=ai x³+bi x²+ci x+di，共4n个系数；不是每节点一段。每段两端插值给2n条，n−1内部节点的一/二阶导连续给2(n−1)条，合计4n−2，**还差2条边界条件**。16:36画面列值/导数拼接关系，口述据此直接称能解完4n个未知数漏了边界。

补充便于计算的二阶导Mi=S''(xi)形式：hi=xi+1−xi，内部i=1..n−1满足

\[
h_{i-1}M_{i-1}+2(h_{i-1}+h_i)M_i+h_iM_{i+1}
=6\left(\frac{y_{i+1}-y_i}{h_i}-\frac{y_i-y_{i-1}}{h_{i-1}}\right).
\]

解出M后，

\[
S_i(x)=\frac{M_i(x_{i+1}-x)^3+M_{i+1}(x-x_i)^3}{6h_i}
+\left(y_i-\frac{M_i h_i^2}{6}\right)\frac{x_{i+1}-x}{h_i}
+\left(y_{i+1}-\frac{M_{i+1}h_i^2}{6}\right)\frac{x-x_i}{h_i}.
\]

以上是补充标准推导形式，用来明确边界和计算依赖，不冒充课程逐步推导。C²要求作用在各段拼接，不是“二阶连续可微就推出最高次三次”；更高次也可C²。

## S04 边界与外推选项（对方法选择有后续影响）

| 选项 | 公式/规则 | 输入与影响 |
| --- | --- | --- |
| F1 自然样条（补充） | M0=Mn=0 | 假设端部曲率0，不能默认等于MATLAB spline |
| F2 夹持样条（补充） | S'(x0)=d0，S'(xn)=dn | 需要两端斜率；MATLAB可给额外端斜率数据 |
| F3 not-a-knot | 第一/第二段三阶导相同，末两段三阶导相同 | MATLAB普通spline调用默认；小节点特殊情况交由实现规则处理，不能盲套段数不足公式 |
| Q1 区间内求值 | q∈[x0,xn]，按所属段计算 | 验证原节点与局部形态 |
| Q2 区间外求值 | 明确声明外推方式/库默认；保留区域标识 | 过采样点不为外推真实性背书；有限三次外延不能复现log在0的发散 |

边界选项对同一数据可产生不同样条，比较时必须记录。当前调用及默认依据：[spline官方文档](https://www.mathworks.com/help/matlab/ref/spline.html)。课程“取两方法平均表示都了解”不是有验证依据的选型规则；平均虽仍过节点，形状/误差保证会改变，应按明确指标或机制选择。

## S05 二维规则网格及多维扩展

输入坐标向量x长度nx、y长度ny，V为ny×nx，V(j,i)=f(xi,yj)。课堂用[X,Y]=meshgrid(x,y)把坐标显式展开，查询网格也展开，Vq=interp2(X,Y,V,Xq,Yq,method)。输出查询曲面，mesh绘图不改变插值结果；二维插值是两个自变量，一个因变量，绘制在三维坐标。

选择A linear：每网格内双线性（补充展开），t=(x−xi)/hi,u=(y−yj)/kj，Vq=(1−t)(1−u)Vji+t(1−u)Vj,i+1+(1−t)uVj+1,i+tuVj+1,i+1。B spline：二维分片三次样条/张量构造按实现完成，课程未给完整二维系数公式，记录调用与网格约定；C cubic等其他方法课堂列名，具体支持条件需按版本，不能视为都等同spline。当前interp2也可用适当网格向量输入，不必所有情况都手工展开。[官方interp2](https://www.mathworks.com/help/matlab/ref/interp2.html)。

多维扩展通常使用interpn及相应网格约定，不是靠把任意函数名中的2改成N就能处理所有维数。二维上机口述为5×5样本网格、21×21查询网格、spline方法；选定帧未拿到完整坐标/Z表达式，不猜补原数据或数值曲面。

## S06 验证、误差与例题

每方法都检查S(xi)=yi（导数方案还检查相应导数）、维度/有限值、边界、是否过冲、查询是否外推。有已知真函数时，在独立查询网格计算误差；无真值时不能只凭图像更光滑宣称更准确。全局高次、等距节点的Runge振荡是特定现象，不能泛称所有分段三次算法均必出现同样Runge现象。

课堂ln例：x=1:10，y=log(x)，q=0.01:0.1:10，共100点，最后9.91，其中10点<1。采用E或F3，分别输出pchip/spline值。补充SciPy重建两者节点残差约0/4.44e−16；q=.01真值−4.60517，pchip−0.89613，not-a-knot样条−1.16519；在0的外延仍有限。因此“更接近0时样条能表现负无穷”不成立，只能讨论某有限区间的误差。独立区间内网格上最大误差约0.02189/0.01238，仅限此数据/网格，不是普遍优劣排名。实际输出见[P24核对](../原始材料/P24/补充插值核对.json)，未执行MATLAB原文件。

自测：唯一性约束是什么？互异横坐标且次数≤n。样条为什么要边界？尚缺两条独立条件。C⁰是不是不可导？不一定。过全部训练点是否说明外推正确？不能。
