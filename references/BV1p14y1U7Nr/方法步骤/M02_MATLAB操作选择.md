## S02 字符与数值怎样组合

课程展示字符向量用 `strcat(s1,s2)` 或 `[s1,s2]` 拼接；不要把这些写法无条件推广成所有字符串类型的完全等价操作。数值 $c$ 需要显示为十进制文字时，先 `num2str(c)` 再拼接。

来源06:30—09:15。课程的 $c=100$ 例子说明，直接将数值与字符向量拼接可能按字符编码处理，而不是得到文字“100”。这是类型选择问题，没有独立的模型公式。

## S03 需要怎样的求和结果

令 $A\in\mathbb R^{r\times c}$。

| 选项 | MATLAB表达 | 公式与输出形状 | 后续使用 |
| --- | --- | --- | --- |
| A 每列求和 | `sum(A,1)` | $u_j=\sum_{i=1}^r A_{ij}$，$1\times c$行向量 | AHP逐列归一化的分母 |
| B 每行求和 | `sum(A,2)` | $v_i=\sum_{j=1}^c A_{ij}$，$r\times1$列向量 | AHP归一化后逐行加总 |
| C 全部元素求和 | `sum(sum(A))` 或 `sum(A(:))` | $t=\sum_i\sum_j A_{ij}$，标量；这里按二维矩阵讨论 | 总量检查与向量归一化 |
| D 未指定维度 | `sum(A)` | 课程以普通多行多列矩阵说明默认按列；通用规则是首个非单例维度，不能对所有形状死记为按列 | 需要确定形状时优先显式写维度 |

来源09:15—14:10。A与B不是可互换写法：维度选择改变输出对象及后续除法能否匹配。

## S04 需要哪些元素与什么形状

| 任务 | 选择/命令 | 输出与检查 |
| --- | --- | --- |
| 取单个位置 | `A(i,j)` | 第i行第j列；MATLAB索引从1开始 |
| 取整行/整列 | `A(i,:)`；`A(:,j)` | 分别保留行向量或列向量方向 |
| 取离散行 | `A([1,3],:)` | 只取第1和第3行，不含第2行 |
| 取连续/等步长行 | `A(1:3,:)`；`A(1:2:3,:)` | 冒号的起点、步长、终点分别决定集合；步长不能为0 |
| 从后面定位 | `A(1:end-1,:)` | 取到倒数第二行；`end`取决于所在索引维度 |
| 所有元素转成列 | `A(:)` | 按列顺序串接；不是按行铺平 |
| 取得大小 | `size(A)`；`[r,c]=size(A)` | 明确二维行列数，后续复制与求和需要匹配 |
| 按块复制 | `repmat(A,m,n)` | A若为$r\times c$，输出$mr\times nc$；是数值矩阵平铺，不是以A为单元的cell数组 |

来源14:10—23:00。索引和复制是操作规则，不强加不存在的模型公式。

## S05 要矩阵运算，还是逐元素运算

| 选择 | 数学含义 | 条件与后续影响 |
| --- | --- | --- |
| `A*B` | $(AB)_{ij}=\sum_kA_{ik}B_{kj}$ | 内维度相等；用于线性代数合成 |
| `A.*B` | $C_{ij}=A_{ij}B_{ij}$ | 本课按同尺寸讨论；用于对应位置加权 |
| `A./B` | $C_{ij}=A_{ij}/B_{ij}$ | 同位置分母须合法；AHP的按列标准化使用此类除法 |
| `A/B` | 解 $XB=A$ | 仅在B为可逆方阵等相应条件下，才可写成 $AB^{-1}$；不能泛化成逐元素相除 |
| `A^2` | $A\cdot A$ | 本课矩阵平方要求A为方阵 |
| `A.^2` | $C_{ij}=A_{ij}^2$ | 各元素平方，与矩阵乘法不同 |
| `A*k` 与 `A.*k` | 标量k缩放所有元素 | 此处k确为标量；不要据此认为非标量时两算符仍等价 |

来源23:00—27:20；补充核对：[MathWorks矩阵与数组运算](https://www.mathworks.com/help/matlab/matlab_prog/array-vs-matrix-operations.html)。这些选择改变的不是显示样式，而是数学运算本身。

**P05末段新增的跨语言选择（27:30—29:00）**：NumPy `ndarray`的`*`对应逐元素乘法，兼容形状可广播；二维`@`对应矩阵乘法，内维不符会报错。不能将“Python可能仍算出结果”的口述泛化为`@`会自动改变运算。MATLAB的`.*`也支持兼容形状的隐式扩展，应按运算符和形状判断，而不是只按语言判断。[NumPy multiply](https://numpy.org/doc/stable/reference/generated/numpy.multiply.html)、[NumPy matmul](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html)、[MathWorks times](https://www.mathworks.com/help/matlab/ref/double.times.html)。

补充区分数学内积与逐元素乘法：$u\odot v=(u_i v_i)_i$输出向量；实向量内积$u^Tv=\sum_i u_i v_i$输出标量。两个二维列向量`*`逐元素乘可算，但`@`直接相乘内维不符；先转置前者再乘才得到内积。NumPy一维数组`u @ v`也可得到内积，但一维数组的形状是`(n,)`，不应把它冒写为二维`(n,1)`。小例子已实际执行，见[P05补充语义验证结果](../原始材料/P05/NumPy重建执行结果.json)。

## S06 需要特征值，还是特征向量也要

## P05补充：先确定维度，再选择操作

P05已完成已取得材料解析；以下依据00:00—12:30本地转写讲解及05:47、11:21抽样清晰画面。矩阵乘法是本讲上机的前置条件，不能因为代码短就跳过维度检查。

**M02-S07-A 矩阵乘矩阵/向量**：输入$A\in\mathbb R^{m\times n}$与$B\in\mathbb R^{n\times p}$时，内维相等才能得到$C=AB\in\mathbb R^{m\times p}$，其元素仍按S05的求和公式计算。列向量$n\times1$、行向量$1\times n$都可视为特定形状矩阵；“向量”的条件是一条维度为1，不能把听写中的“至少一个位置是一”误解为某个数值元素必须等于1。

课中$A$为3×3、$C$为3×2，则$AC$可算且输出3×2，$CA$内维2与3不合，不能算；$A\alpha$对3×1列向量可算，对1×3行向量$\beta$的$A\beta$不能算。即使AB与BA都可算，也一般不相等。因此M03的行权重乘评价矩阵不能直接交换顺序。

**M02-S07-B 标量缩放**：输入标量$\lambda$和向量$\alpha$，输出为相同形状的$\lambda\alpha$，逐分量乘以同一数。它与S07-A不是同一运算；不能仅因结果形状相同就认定$A\alpha=\lambda\alpha$对任意向量成立。

**与S06衔接的定义**：方阵$A\in\mathbb R^{n\times n}$若存在非零向量$\alpha$及数$\lambda$使$A\alpha=\lambda\alpha$，则$\lambda$是对应特征值、$\alpha$是对应特征向量。非零条件排除了任何A都满足$A0=\lambda0$的无信息情形；$\lambda$本身允许为0。此定义说明AHP所用特征值的含义，不表示P05的模糊评价合成需要重新求特征值。

## S08 按列极值与逐元素比较

P09新增的极值操作选择：`max(A,[],1)`沿行维减少为每列最大值，输出1×m；`max(A,[],2)`得到每行最大值，输出n×1。`max(A,1)`则是A与标量1逐元素比较，计算$\max(A_{ij},1)$，不是选择第1维；当A全不大于1时得到全1数组。空参数`[]`用于区分函数签名，不是可随意删除的装饰。最小值操作也应明确目标维度。[MathWorks max](https://www.mathworks.com/help/matlab/ref/double.max.html)。

## S09 判断元素存在，还是取得位置

P14区分如下选择：`ismember(j,x)`对标量j返回是否出现在x中的逻辑值，适合直接作条件；`find(x==j)`返回匹配位置，若要判断是否不存在，可用`isempty(find(x==j,1))`。两者输出不同，不能把位置向量直接当已定义的标量真假值。

`exist`检查变量/文件/函数等名字是否存在，不是数值向量成员查询。对固定整数标签可直接比较；本课没有讨论浮点近似相等的容差，不把精确成员检查推广到带舍入误差的数值匹配。[ismember文档](https://www.mathworks.com/help/matlab/ref/double.ismember.html)、[exist文档](https://www.mathworks.com/help/matlab/ref/exist.html)。
# S10 上三角转对称矩阵与diag（P18新增）

来源P18 20:00—27:14。输入上三角U，未填写的下三角为0；输出对称矩阵。A 若对角全0，B=U+U.'；B 若要保留原对角，B=U+U.'−diag(diag(U))。diag(U)从矩阵取对角向量，diag(v)把向量放上对角形成矩阵，两次调用不是同一输入语义。课程实数用U'与U.'数值相同，复数时前者共轭转置，后者仅转置；不能随意混用。

检查：公式只适于下三角尚为0的上三角输入；完整对称矩阵再次相加会把非对角边权也翻倍。课堂将对角改为[0,2,3,0]示范重复相加问题，修正后应原样保留该对角；非零对角是否需要作为自环，另按建图任务判断。Excel选择性粘贴的转置和跳过空单元是课堂操作分支，无额外数学公式，不能把空白与数值0在所有导入场景都视作相同。
