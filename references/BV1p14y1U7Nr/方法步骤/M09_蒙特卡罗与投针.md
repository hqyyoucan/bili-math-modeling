# M09 蒙特卡罗：以蒲丰投针为例

来源P13约17:00—22:00、P14的投针与随机优化上机，已核对两讲抽样图。蒙特卡罗是用随机抽样估计量的数值方法，不等于整数规划，也不自动提供全局最优证明。

## A路线：投针概率与π估计

| 步骤 | 输入、选择及公式 | 输出与检查 |
| --- | --- | --- |
| M09-S01 建概率模型 | 平行线距a，针长l，课程短针条件0<l<a | 几何事件；超出条件不能沿用同一概率式 |
| M09-S02 按模型抽样 | 中点最近距离d独立均匀于[0,a/2]，角φ均匀于[0,π] | N对随机样本，记录参数、种子、次数 |
| M09-S03 判相交 | $I_k=1[d_k\le(l/2)\sin\phi_k]$ | 0–1指示量；角度用弧度 |
| M09-S04 频率估计 | $K=\sum_kI_k,\hat p=K/N$，N>0 | 交线次数与概率估计 |
| M09-S05 恢复π | 理论$p=2l/(\pi a)$，故$\hat\pi=2l/(a\hat p)$ | K>0才定义，不能在零交点时除零 |
| M09-S06 检查误差 | 有限样本存在波动，比较理论值/重复实验 | 报告近似与抽样设置，不声称每次增样本都改善 |

角度与位置独立、均匀，是课件把阴影面积比当概率所需的模型条件，不能任意改成另一分布。公式推导为

$$p=\frac{\int_0^\pi (l/2)\sin\phi\,d\phi}{(a/2)\pi}=\frac{2l}{\pi a}.$$

距离d的全部取值范围是[0,a/2]，相交事件的上界为$(l/2)\sin\phi$，不要把两个上界混成同一个数。针较长或投掷分布不满足假设时，应重新推导模型。

补充误差说明：独立同分布指示量下，频率标准误差可估为$\sqrt{\hat p(1-\hat p)/N}$，常见误差量级随$N^{-1/2}$缩小；不是每一轮结果都必然更接近真值。π估计还含倒数变换，有限样本不应当作精确或无偏的π。

已补充模拟a=2、l=1、N=200000、seed=20261117，交线63643次，$\hat p=.318215$、$\hat\pi\approx3.142529$。这些数值参数是明确自定的补充演示，课堂只有符号模型；[实际执行记录](../原始材料/P13/补充数值核对.json)保存理论p、频率标准误差及误差，未伪称课堂输出。

P14上机补充了课堂参数a=10、l=5、N=10000，代码为`phi=rand(n,1)*pi`、`x=rand(n,1)*a/2`、`y=(l/2)*sin(phi)`，逐点判断x≤y并累计m，最后P=m/n、`mypi=2*l/(P*a)`。课堂口述一次结果3.2154，种子未给；补充实现自定种子20261119得到3.123048，两者不是同一随机序列，不能声称重现了某次课堂数值。

## B路线：约束优化的随机可行搜索（P14）

此路线估计的是“抽到的候选里最好者”，与A路线估计概率后反解π的目的不同。

| 步骤 | 已知编码/选择与公式 | 输出、边界及后续 |
| --- | --- | --- |
| M09-B-S01 写原模型 | 原目标f、完整可行域F、有限采样域Ω | 不先删约束来提高通过率 |
| M09-B-S02 抽候选 | 学校6个二元值；设备6个企业编号；人员2个整数 | 一个候选x；抽样分布及N需记录 |
| M09-B-S03 可行筛选 | 只在$x\in F$时进入目标计算 | 不可行则跳过本轮；不要误终止全部抽样 |
| M09-B-S04 更新最好 | 最小化初始B=+∞；最大化B=-∞；只对更优可行值更新 | 同时保存B与对应x，不能只更新目标忘记方案 |
| M09-B-S05 停止与报告 | 课程固定N=10000次 | 输出最好可行解、N、可行样本数、种子；未找到可行样本不等于无解 |
| M09-B-S06 另行验证 | 回代全部约束；小域可全枚举或用求解器/界认证 | 区分随机样本最好与已证明全局最优 |

**编码选项一：学校**。课程`randi([0,1],6,1)`产生二元列向量；按M08完整8小区覆盖矩阵检查$Cx\ge1$，目标$\sum_jx_j$。只有全部覆盖才更新学校数。

**编码选项二：设备**。课程`randi([1,4],1,6)`产生标签向量$s=(s_1,\ldots,s_6)$，$s_i$是设备i所属企业；一台只取一个标签，天然满足每设备恰分一次。再检查每个企业j至少出现一次，收益$f(s)=\sum_{i=1}^6c_{i,s_i}$。与M08二元矩阵对应为$x_{ij}=1[s_i=j]$，不能把标签值本身当利润。

**编码选项三：人员**。P14末尾随机筛选人数与资源约束，口述得(4,2)、220。完整采样范围未进入本次帧；补充实现由题设选$\Omega=\{1,\ldots,6\}^2$，明确标为补充，未猜成教师代码逐字内容。

更新规则是保留最好记录：对最小化，若x可行且$f(x)<B$，令$(B,x^*)=(f(x),x)$；最大化把小于改为大于。课程最大化初值0在本例全部正利润下可用，若一般题的可行目标全为负，初值0会导致不记录任何真实解，故补充用-∞和“已找到可行解”标记。

只存严格改善的一个方案，并没有枚举全部并列最优解。不同次随机结果不同不自动证明原题多解，要分别核对可行性与目标；同次反复得到同一方案也不证明唯一。

补充概率说明：若Ω有限、独立均匀抽样、全局最优状态有K个，则N次未命中任何最优状态的概率为$(1-K/|\Omega|)^N$。一般题K未知，不能据固定10000次保证最优；抽样次数增加也不能修复漏约束或模型错误。
