# 方法的解题步骤、选项与公式

## 记录单位与范围

每个方法建立一份步骤记录。保留课程中的实际变体：同一名称在不同课中采用不同前提、顺序或符号约定时分别记录，再解释共同点和差异。不要把多个来源的零散步骤拼成看似由老师完整讲授的流程。

为方法、步骤、选项和公式分配简短稳定的局部标识，例如 `M01`、`M01-S02`、`M01-S02-B`、`M01-S02-B-F1`。标识用于跨笔记、例题和代码回查，显示时同时写可读名称。追加内容不随意重编号。

覆盖课程讲到的所有步骤和选项；课外补充仅在帮助理解、必要验证或用户要求时增加，并标记来源。不能列举声称穷尽全领域的“所有选择”，也不能把没有讲到的分支当作课程内容。

## 方法级路线

先写方法目标、适用题型、前提、输入输出和课程来源，再列实际解题顺序。对条件分支写明判断条件与去向；对迭代写明初始状态、更新顺序、收敛/停止条件与失败退出情形。

先给步骤总览，再按步展开。每步需回答：

| 字段 | 必须说明的内容 |
| --- | --- |
| 步骤标识与名称 | 在本方法的位置及步骤要解决的问题 |
| 目的与输入 | 使用哪些原始数据、上一步输出、参数或已知量 |
| 输出与后续 | 得到什么对象、形状/单位，以及供哪个步骤使用 |
| 可选方案 | 每个已知选择分别列出；区分互斥替代、条件分支和可组合子步骤 |
| 选择依据 | 数据性质、题目要求、假设或评价目标如何决定采用哪项 |
| 公式或操作 | 对每个选择绑定其公式标识、推导前提或具体算法规则 |
| 检查与异常 | 该步的合法范围、维度、边界、失败信号及异常处理 |
| 来源与状态 | 分P/时间/页码/代码位置；课程内容、补充或待核实 |

将“可选方案”与“公式”一一关联：一个选择含多条公式就记录执行次序；多个选择共用公式则明确引用同一公式，指出改变的参数或输入。不要单独堆放无法对应步骤的公式表。

## 每个选项的公式记录

每个选项采用如下信息组织，可用段落或短表，避免把长 LaTeX 挤入宽表：

- **标识与名称**：属于哪个方法、哪一步及哪个变体。
- **什么时候选**：可判断的条件、与其他选择的取舍和不可用情形；老师未说明理由时写“课程未说明”，补充分析另标。
- **公式**：按使用顺序写完整表达式；定义变量、参数、下标范围、维度/单位及必要的定义域。
- **参数与约定**：参数从哪里取得或估计；计算基于原数据还是上一步结果；归一化方向、分母口径等容易混淆的约定。
- **计算检查**：如零分母、非法对数、尺度不匹配、不可行条件；异常处理依据不明确时不要自行添加后冒充课程做法。
- **输出与影响**：输出的含义、形状、范围，以及本选项会使哪些后续步骤或公式发生变化。
- **来源与确认状态**：提供定位，标明公式已核实、存在歧义或尚未取得。

操作性步骤可能没有公式，如识别指标含义或读取数据，应写明“无独立数学公式”及具体判定/执行规则。有公式但资料缺失时写“公式未取得”，二者不得混淆。

符号只有在定义一致时才统一；同一符号在不同课或步骤中含义不同时显式换名并给映射。等价公式可以注明等价条件；不能因名称相同就判定公式可互换。

## 例题与代码所走的路线

对实际例题列出“步骤 → 采用的选项 → 对应公式 → 选择理由 → 代入量 → 中间结果 → 检查结论”。数据或结果缺失时记录未知，不以自拟数字填充课程证据。

关键代码段或函数关联相同的步骤与公式标识。检查实际执行顺序、输入和参数是否与记录一致。更换上游选项时沿依赖关系识别需要重算的步骤，不把旧路线的中间值带入新路线。互不兼容的变体分开执行，不能任意排列组合。

## 保存、重读与增补

将记录保存在 `方法步骤手册.md`，或短课笔记的“方法步骤手册”章节。长课可拆为 `方法步骤/方法短名.md`，并在总览维护索引；索引至少列方法/变体、步骤记录位置、已覆盖选项与未核实缺口。

继续处理同一课程或回答后续问题时，先查索引、读取对应方法和有关步骤，再使用公式。其他课程也可引用已有记录，但必须检查适用条件、变体和材料来源，不默认通用。

新分P、用户纠正或公式查证改变原记录时，就地更新相应条目，保留原课程表述、变更依据及影响的例题/代码。实际文件才是可重读的记录，不能用“我记住了”代替保存。

## 交付检查

抽取一个材料中存在分支的方法，沿一条实际例题路线检查：每个已覆盖步骤是否有输入输出，每个已记录选项能否找到公式/操作规则或明确缺失状态，选项间是否兼容，公式所用量能否追溯到输入或前一步。无分支的材料按单一路线检查，不编造分支。

读者应能回答：“下一步做什么？这一小步有哪些已知选择？根据什么选？选完用哪条公式？输出交给谁？如果换选项，后面哪里要重算？”证据不足的问题列为缺口，不把空缺隐去。
